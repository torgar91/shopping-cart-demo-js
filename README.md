# 🛠️ Carpintería Mazarredo - Mini tienda interactiva

Este proyecto es una práctica desarrollada con **HTML**, **CSS** y **JavaScript nativo**, en el que se simula una tienda online de carpintería. Incluye lógica de carrito, control de cantidades, cálculo de precios y una interfaz responsive.

## ✨ Funcionalidades

- Añadir y quitar productos con botones
- Mostrar cantidad e iconos según cada unidad
- Contador total en el carrito del menú
- Vista responsive para móvil y tablet
- Resumen del pedido al hacer clic en el carrito

## 🧠 Tecnologías usadas

- HTML semántico
- CSS con Flexbox y media queries
- JavaScript DOM puro
- Git & GitHub
- GitHub Pages
